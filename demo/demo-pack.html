Nova Bank support copilot

An assistant for Nova Bank's contact-center agents. It drafts answers to dispute, fee and card questions from Nova's own policies and the verified customer's own records. Every claim is cited and checked, and it never approves anything.

Live product: agent consoleModel: Claude Opus 5.5, synthetic data onlyLanguages: English, formal Arabic, Egyptian Arabic, Franco-Arabic

System design

How one draft is made

Demo build

  • Python FastAPI backend, single-page agent console
  • Claude Opus 5.5 with structured output; Claude Haiku 5.5 as the independent promise check
  • All 20 policies in a cached system prompt (cheaper and more accurate than search at this size)
  • Synthetic data: 50 customers, 720 transactions, 25 disputes, 200 tickets

Production design

  • Customer data, logs and the model stay in Egypt (Huawei Cloud Cairo or self-hosted), because bank secrecy rules block offshore processing
  • Model behind one interface, so the provider can change without rework
  • Search over policies once the library grows past a few hundred pages
  • Same eval suite gates any model change

Compliance

Questions a compliance officer will ask

Does any customer data leave Egypt?

Not in production. Data, logs and the model run in Egypt, and masking happens before any model call. The demo uses synthetic data only. Banks fall outside the data protection law (PDPL Art. 3); bank secrecy under Banking Law 194/2020 Art. 140-143 is the binding rule, with criminal penalties.

Can the copilot move money, waive a fee or approve a dispute?

No. It can only suggest an action, and each suggestion names who must approve it: the agent, a Team Leader, the Disputes team or the Credit team. That matches the human-final-decision principle in Egypt's 2023 Charter for Responsible AI.

Could an agent see another customer through it?

No. Each session is bound to the customer on the verified case, and the model is given only that customer's records. A request about anyone else is refused and flagged.

Who is accountable if it states a wrong fee?

The bank, under CBE consumer protection rules. That is why fee answers come only from the current tariff with a citation, numbers are checked against the source, and the agent sends the reply.

Can you prove what it said and why?

Yes. Every draft is logged with the masked input, the sources it was given, each guardrail result and the agent's action. The eval suite is the documented test evidence the 2026 national AI guidelines ask for.

Roadmap

From demo to customer-facing

Now
Demo

Agent copilot on synthetic data, 41-case eval suite, audit log.

Weeks 1–8
Pilot with 20 agents

In-country model behind the same interface; written CBE view on masked prompts; a form-of-address field (Mr/Ms) from the CRM so Arabic replies use the right gender without sending the name. Goals: 2 minutes off in-scope handle time, citations correct in 98% of drafts, zero leaks, agents accept at least 60% of drafts.

Months 3–6
All 120 agents

Complaint timer for the CBE 2- and 15-working-day limits, card-scheme deadline warnings, weekly review of flagged drafts.

Month 7+
Customer-facing in the app

Fee explanations and dispute status first, labelled as AI, one tap to a human. Anything that moves money goes to a person. Goal: 30% of in-scope contacts resolved in the app.

Later
Beyond support

The same grounded, approval-gated pattern for SMB loan underwriting (9 days today), with the Credit team deciding.
